# 正心Translate 帮助

## 关于正心Translate

正心Translate 是一款面向 macOS 的本地整书翻译工具，支持 Apple Silicon 与 Intel 芯片。

软件使用 SwiftUI 和 AppKit 开发，基于以下组件构建：

- **TranslateGemma 4B**：用于本地文本翻译，按照 Google《Gemma 使用条款》提供。
- **llama.cpp**：用于在本机运行 TranslateGemma 模型，按照 MIT License 授权。
- **BookForge**：用于书籍和文档的结构处理，按照 MIT License 授权。

TranslateGemma 不是采用 MIT License，而是受 Google《Gemma 使用条款》和禁止使用政策约束。除上述第三方组件外，正心Translate 的界面、功能设计及相关软件成果版权归北京正笔正心文化发展有限公司所有。

[查看 Gemma 使用条款](https://ai.google.dev/gemma/terms)

## 如何使用

### 1. 准备模型

打开正心Translate 后，软件会自动检查模型状态。未找到模型时，会自动从 Hugging Face（MoMonir）下载约 2.49 GB 的 TranslateGemma 4B 模型到 `~/Library/Application Support/正心Translate/Models/`，下载后自动检查文件大小、GGUF 文件头和 SHA-256 校验值，通过后才启用模型。下载失败后，可以点击“重试下载模型”重试。显示“模型：已就绪”后，即可开始翻译。也可以点击“验证本地模型”，重新检查模型文件。

### 2. 选择输入文件

点击“输入文件”右侧的“选择……”按钮，选择需要翻译的文件。

当前支持 EPUB、文本型 PDF、Word 文档（DOCX）、TXT 文本文档和 Markdown 文档（MD）。PDF 仅支持能够直接选择和复制文字的文本型 PDF，不支持扫描版 PDF 和图片型 PDF。

### 3. 设置输出位置

点击“输出目录”右侧的“选择……”按钮，指定翻译结果的保存位置。

### 4. 选择翻译语言

点击源语言或目标语言后，列表先显示13个常用语言。列表底部的“更多”可以逐级展开，已显示的语言保留在上方，新增语言接在下方：

- 第一次点击“更多”：扩展到55种语言。
- 第二次点击“更多”：扩展到160个基础语言。
- 第三次点击“更多”：再加入421个地区或文字变体，此后不再显示“更多”。

展开后可向下滚动浏览；点击语言即可选中并关闭列表。重新打开列表时从常用语言开始，当前选择仍保留。源语言列表另有“自动检测”，目标语言不提供此项。菜单显示中文名称及语言代码，便于区分地区和文字变体。基础中文以简体中文快捷项显示，繁体中文等可在最后一级选择。

55种语言是便于浏览的分组，并非官方评测名单。完整选项来自当前 GGUF 的内置语言表，部分语言的翻译质量需要自行核验。

分别选择源语言和目标语言。源语言可以选择“自动检测”。对于内容复杂、包含多种语言或者语言特征不明显的文档，建议手动指定源语言。

### 5. 选择输出格式和模式

输出格式支持 Word 文档和 Markdown 文档。输出模式支持“仅译文”和“双语对照”。

### 6. 检查术语建议

软件会根据文档内容自动提出术语建议。打开“术语建议”窗口后，可以确认、修改或忽略术语。已经确认并锁定的术语会在后续翻译中尽量保持一致。

### 7. 开始翻译

点击“开始翻译”执行任务。翻译过程中可以暂停、继续或取消任务，并查看实时进度、当前处理位置和任务日志。

### 8. 检查翻译结果

任务完成后，可以打开“检查列表”，查看翻译失败、需要人工确认或可能存在问题的段落。点击“打开结果”，可在访达中查看生成的 Word 或 Markdown 文件。

机器翻译可能无法准确处理专业术语、历史语境、双关、典故和复杂格式。正式出版或对外使用前，请进行人工校订。

反馈问题时，建议同时提供正心Translate版本号、macOS版本、芯片类型、输入文件类型、错误提示或任务日志，以及能够复现问题的操作步骤。

请勿提交包含个人隐私、未公开资料或无权传播内容的原始文档。

模型下载会分别显示“正在连接”、下载百分比及已下载数据量、文件校验状态。开始连接后 20 秒内未收到任何模型数据，或传输中连续 30 秒未收到数据时，将停止等待并显示具体错误。连接、网络或 HTTP 错误会显示在模型状态区域及任务日志中；点击“重试下载模型”可重新连接并重新下载。下载期间验证按钮禁用，避免重复请求。更换代理或恢复网络后可重试；重试不支持断点续传。
